# Bill Management System

A Java-based Bill Management System built using Swing and Maven.

## Features

- Admin login
- Customer management
- Generate electricity, gas, and water bills
- Customer dashboard
- Bill payment status
- File-based data storage

## Technologies Used

- Java
- Java Swing
- Maven
- File Handling
